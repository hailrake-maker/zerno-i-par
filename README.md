# Зерно и Пар — демо-лендинг кофейни

Демо-проект для портфолио: лендинг вымышленной кофейни. Сделан с нуля на чистом HTML, CSS и JavaScript, без фреймворков и конструкторов.

**Смотреть сайт:** https://hailrake-maker.github.io/zerno-i-par/

## Что внутри

- Адаптивная вёрстка: телефон, планшет, компьютер
- Иллюстрации на SVG и CSS без фотографий: чашка с анимированным паром, вращающийся бейдж, парящие зёрна
- Меню с вкладками и плавным переключателем
- Слайдер отзывов и раскрывающиеся вопросы
- Форма брони с маской телефона, проверкой полей и экраном подтверждения
- Статус «Сейчас открыто» по минскому времени
- Появление блоков при прокрутке и поддержка настройки «уменьшить движение»
